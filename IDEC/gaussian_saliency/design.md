# Can a cluster saliency map improve Gaussian-weighted reconstruction?

The primary comparison adds image-specific saliency to the existing fixed Gaussian during pretraining. Use the same 12,000 MNIST fitting images, 10,000 test images, five student seeds, two detached symbols, unweighted IDEC fine-tuning and existing pixel and Gaussian controls. Outcomes are marked accuracy, clean accuracy and redraw flips. These test images have appeared in previous studies.

Fit one ordinary pixel autoencoder and ten K-means centers on the unlabeled fitting images of each domain (teacher seed 126). For an observed training image, take its nearest two centers in teacher embedding space. Define the margin as the squared distance to the runner-up minus the squared distance to the winner. Take the absolute input-times-gradient of this margin. Average over a 3-by-3 neighborhood. For each pixel form a saliency value s = a/(a + image mean of a), using zero for a blank map, and store it to 8-bit precision. The modulation 0.5 + s stays bounded. Multiply by the mean-one fixed Gaussian (sigma seven) and renormalize each map to mean one. Freeze the weights while training a new student. Inference uses only the student encoder and cluster centers.

Test saliency alone, Gaussian times aligned saliency, and Gaussian times another image's saliency. Reassign maps by one seeded cycle across all fitting images so every donor is different and every map is used once. This controls whether matching saliency to the particular image adds value over its general spatial pattern. Use the same teacher and maps for all new arms and seeds within each domain. Keep the original pretraining and clustering budgets for each student. The teacher adds training cost. Use the synthetic masks only after constructing the maps to measure the mean weights on digit ink and on symbols.
