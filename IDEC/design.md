# Study design frozen before the stripe experiments

Prior evidence consisted of a clean MNIST pilot with shortened pretraining. The new experiment starts from scratch. The experimental unit is a model seed, paired across all arms. One train subset, one held-out test set and one orientation assignment are shared by all seeds.

**Question.** Does fine-tuning with pixel reconstruction preserve irrelevant stripe orientation at the expense of digit clustering? Can we reduce this effect by removing one known nuisance direction from the reconstruction loss?

**Predictions.** For standard IDEC, strong stripes should reduce test digit ACC and increase orientation NMI relative to clean data. At strength 0.8 the projected loss should improve paired test digit ACC and reduce orientation dependence relative to standard IDEC. Near-zero effects at strength zero would indicate little cost on clean images. Directional differences from five seeds are descriptive.

**Intervention.** Add a fixed-phase horizontal or vertical square wave, alternating every two pixels between −0.5 and +0.5, to the original image at strengths 0, 0.3 or 0.8. No clipping. Assign orientations by a balanced random permutation independently of labels. For a given digit, changing orientation moves its input by a known multiple of a single vector. Let d be the unit horizontal-minus-vertical template. Project the reconstruction residual r onto its orthogonal complement, r − (r·d)d. This removes the cost of orientation contrast while still reconstructing the remaining 783 dimensions. The encoder continues to see the full striped image; it may retain orientation through pretraining or the clustering loss.

**Training.** Raw intensities and stripe perturbation are both multiplied by 255/50 for IDEC. A separate plain AE is pretrained on each strength and seed. All three fine-tuning arms start from identical weights and K-means centers within that pair. The third arm keeps only the clustering term. All arms run the same fixed 5,600 updates with identical batches and target refreshes. Record ongoing assignment changes rather than using early stopping. Report AE + K-means as a shared initialization reference. No class or orientation labels enter losses, initialization selection, or stopping decisions. The analytic stripe templates are known to the projected method.

**Evaluation.** Fit cluster-to-digit Hungarian mapping on training labels only after training and apply to the 10,000 test images (primary ACC). Report digit NMI and ARI, cluster-orientation NMI, and fraction of test images whose cluster changes when the same digit switches stripe orientation. At zero strength the two inputs are identical. Save per-image predictions, training traces and elapsed time. Compare matched seeds, report means and sample standard deviations, retain all conditions. These comparisons condition on one digit dataset and a known artificial interference pattern.
