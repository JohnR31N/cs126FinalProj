# Selecting reconstruction features from reproducible clusters

The previous clean-image experiment tested whether a pixel predictable from neighboring images deserved more reconstruction weight. Its mean digit accuracy fell below ordinary IDEC. Here the working assumption is that features useful for digit clustering separate groups that can be recovered independently from different samples. The handwriting prior is local gradient orientation. All inputs are original MNIST images.

## Selection and controls

Represent each image by square-rooted gradient-magnitude histograms on a 7 by 7 grid with eight unsigned orientations per cell, followed by whole-image L2 normalization. These give 392 measured stroke features. Divide the project's 12,000 training images into two disjoint halves. On each half, cluster a 15-nearest-neighbor graph using locally scaled affinities, ten normalized spectral coordinates and K-means. Each partition assigns the other half by a 15-neighbor vote. Align the arbitrary group numbers by agreement across the training images. Use the images on which both partitions agree to estimate between-group and within-group scatter. The selector has access only to the training images.

Select the leading nine regularized Fisher directions, the maximum between-group rank for ten groups. Use a within-group ridge of 0.1 times the average within-group variance. These directions combine the measured gradient features. All student training examples, including those on which the two partitions disagree, get continuous targets by projection. Fit a nine-direction PCA control and a nine-direction Fisher control with permuted pseudo-group assignments to the same agreed examples. Use an orthonormal basis for each selected span. Keep an all-392-feature control and a complementary projection that removes the selected span. Center feature targets and match their total mean squared magnitude to the ordinary pixel target using training images only. Embed the targets isometrically into the same 784-output decoder using a fixed label-independent basis. The input, encoder and decoder architecture, batches and optimization budget are matched.

Compare ordinary pixel IDEC, all gradient features, the selected span, its complement, PCA and permuted-group selection. For the ordinary and selected targets also fork KL-only fine-tuning from the exact same pretrained weights and centers. Record the K-means initialization as well as the fitted models. Use the original five seeds, 100 autoencoder pretraining epochs and 5,600 clustering updates. Feature selection is fitted once and held fixed across student seeds. No labels, synthetic marks, augmented views or corrupted targets enter any fit.

## Evaluation

The primary comparison uses the 10,000 original test images. Also score the other 48,000 original MNIST training images excluded from every selector and student fit in this study. The official test split has appeared in earlier project experiments. Fix all methods before consulting either set of digit labels. Use a training-only cluster-to-digit mapping after fitting, with NMI and ARI as secondary metrics. Report all paired seeds. Also score the unsupervised graph itself by out-of-sample voting and fit K-means directly on the retained, discarded and control feature coordinates. The graph reference measures how much digit structure was available to the selector before training IDEC.

Assess known sources of within-digit variation separately using post-fit linear probes for ink mass, horizontal and vertical center of mass, and slant. Fit the probes and the digit-conditional means on the training split and evaluate their predictive power on both holdouts. Useful digit information may remain in the complement. Reduced linear predictability of a writing attribute is evidence about that attribute and probe.

The spectral grouping and cluster-separation criterion draw on earlier work. This project combines them with a feature reconstruction target for IDEC.
