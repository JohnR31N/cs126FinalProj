# Fisher reconstruction at the rank supported by the CIFAR-10 partition

The earlier fixed-nine rule could not fit grayscale CIFAR-10. Its two unlabeled graph partitions agreed on 5,881 of 12,000 training images. Nine aligned groups contained agreed examples. We know these counts, the ordinary pixel IDEC and graph scores, and the original graph's class composition before this follow-up. This is an exploratory follow-up on the same test set.

Reuse the exact training indices, aligned groups and locally measured 392 gradient features from the external benchmark. Fit a regularized Fisher subspace on agreed training examples, using every occupied group and retaining the maximum between-group dimension (nine groups minus one, giving eight). Use the same within-group ridge as the original selector, 0.1 times the mean diagonal within-group variance. Each occupied group requires two examples. The IDEC student still predicts ten clusters. The PCA control fits eight directions on the same agreed examples. Use all 12,000 training images to train both students, including images excluded from the selector fit.

Give all methods the identical 28-by-28 grayscale input. In both stages, use the existing fixed embedding and energy matching for the eight-dimensional targets. Retain the previous network, 100 pretraining epochs, K-means initialization, 5,600 clustering updates and student seeds 0 to 4. Compare with the archived pixel IDEC predictions from the identical split, training budget and seed set. Score each model by matching classes on training assignments after fitting and freezing this mapping on the 10,000 official test images. Primary outcomes are paired changes in held-out accuracy for Fisher minus pixel and Fisher minus equal-width PCA. Report the five differences, sample SD and win count. NMI and ARI are secondary.

This comparison tests the effect of replacing pixel reconstruction and the choice of directions at fixed width. An object's class and its background both influence images. There are no ground-truth background masks or background interventions in this follow-up.
