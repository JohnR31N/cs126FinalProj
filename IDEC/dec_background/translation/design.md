# Whole-image translation control for the matched DEC and IDEC comparison

This addendum fixes the comparison before fitting the translated DEC forks. The earlier translated IDEC result on varied backgrounds (77.63% marked ACC), the separate mark-free augmentation experiment, and all v1.8 controls are already known. Use the released v1.8 DEC and IDEC predictions as the ordinary controls, paired by domain and seed. The clean and marked results for the translation condition will both come from this addendum.

Regenerate the exact 12,000 training digits and 10,000 held-out digits, placements, templates and redraws in the existing two-symbol experiment. For each training domain and seed (0--4), pretrain one autoencoder for 100 epochs with the existing translation policy. At each epoch, sample a horizontal and vertical integer displacement per image within three pixels of zero that keeps every nonzero pixel in frame. The digit and any symbols move together. Feed and reconstruct the same translated image with uniform MSE. Record the legal-offset counts for each domain because edge symbols may constrain motion.

Fit K-means on the unshifted training embeddings. Fork DEC and IDEC from identical weights and centers in each cell. Fine-tune on the original unshifted training inputs for the same 5,600 updates as v1.8. DEC uses only the matched clustering KL term and IDEC adds uniform image reconstruction. Save assignments for training digits, clean test digits, and all three marked test views. For translated IDEC also retain the existing decoder readout for the first background redraw.

Fit each cluster-to-digit mapping after training using training labels only. For each method, report clean-trained/clean-tested ACC, marked-trained/marked-tested ACC, their within-seed difference (clean minus marked), and the assignment flip rate when only the background is redrawn. Compare the two translated methods' drops within seed. Compare each translated method with its fixed v1.8 control: gains in each domain, decrease in the drop, change in redraw flips, and the effect of adding marks only at test time to frozen clean-trained models. Report all five differences, their mean and sample SD. Compare translation to the Gaussian pretraining arm descriptively. These comparisons test performance and sensitivity, not removal of background information from the embedding. Whole-image translation leaves the cost of omitting a translated symbol intact.
