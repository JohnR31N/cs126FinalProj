# Reconstructing task-relevant content

Digit identity is the clustering target. Pixel reconstruction can reward encoding class-independent background appearance. We use the foreground that persists across controlled background replacements as a proxy for content relevant to digit identity. This follow-up was designed after the additive-overlay study and before fitting the layered models.

**Image formation.** Use the original nonzero MNIST pixels as an opaque foreground, including faint stroke edges. Fill only originally zero pixels with a synthetic background. Use the original split (12,000 training and 10,000 test digits), orientation assignments, five seeds and optimizer budgets. Training backgrounds alternate between black and gray (0 and 0.4 on the unit scale) every two rows or columns.

**Training comparison.** Full-pixel IDEC reconstructs the observed composite during pretraining. The proposed pretraining target retains pixel values that stay fixed across two aligned views of the same digit, and sets changed pixels to zero. For the auxiliary view, invert the two background levels so that every background pixel changes. Keep the same single input view, initialization seed, minibatch order, architecture and optimizer. Both arms then use ordinary IDEC fine-tuning for 5,600 steps. Only the proposed target uses the training pair. The loss construction uses neither stripe templates nor class labels. This design supplies paired views during training and assumes all background pixels vary across the pair.

**Prediction and evaluation.** Predict a lower horizontal/vertical test flip rate under the paired target, with improved digit ACC as a separate prediction. Freeze each model and its cluster-to-digit mapping fitted on training labels after optimization. Report held-out ACC on the identical digits with a clean black background, with the assigned stripes, and with a previously unseen 2-by-2 checkerboard of the same contrast. Record all seeds, sample SD, paired differences, and the number of occupied test clusters. Check every foreground pixel for exact preservation under every rendering and check the derived training target against the clean layer. The experiment identifies sensitivity of cluster assignments. It does not measure whether a latent code contains all recoverable background information.
