# Geometric backgrounds and task-relevant reconstruction

Digit identity is the grouping target. Full-image reconstruction can reward retaining class-independent background features. Our working principle is to reconstruct content that persists across controlled changes of background. This geometric design replaces the planned layered-stripe follow-up before any model fit. The earlier additive stripe studies retain their own designs and observations.

**Intervention.** Add one white plus or diagonal cross to otherwise black MNIST background. Both symbols occupy nine pixels in a 5-by-5 box. Every box and its one-pixel border inside the image must be free of nonzero digit pixels, including faint edges. Select two nonoverlapping legal boxes without using labels, with placement RNG seeds 2701/2702 for train/test. A geometry-only feasibility check found that all 22,000 images admit these placements at size five. A balanced random assignment gives each training digit one input symbol. Test four views of each digit: its assigned symbol, the other symbol at the same site, the same symbol at the other site, and no symbol.

**Compared objectives.** Pretrain on the complete composite input. Ordinary reconstruction targets that image. Paired-target reconstruction retains pixel values shared with a second view of the same digit in which the symbol has moved to a disjoint site, and sets changed pixels to zero. The target builder uses only paired pixel values. Only that arm uses the auxiliary view as a training signal. Both arms use ordinary IDEC fine-tuning, the original 12,000/10,000 split, five paired seeds, 100 pretraining epochs and 5,600 fine-tuning updates. Use the same random starting weights and batches per seed. Refit K-means for each pretrained embedding.

**Predictions and metrics.** Predict that changing the pretraining target reduces final cluster switches when the symbol moves (primary), and when its shape changes at fixed location (secondary). Digit ACC is a separate outcome. Compare each frozen model and its fixed training-label mapping on marked and clean versions of identical test digits. Save assignments, check every stroke and guard band, report per-seed values, mean and sample SD. Retain weak or opposite effects. Visible separation protects the original pixels but a background object can still change perceived shape. Invariance to these paired edits is a proxy for relevance. The experiment supplies the pairs and does not identify arbitrary nuisance features in unpaired natural images.

**Amendment before fitting.** Compare four pretraining arms. (1) Ordinary full reconstruction of the fixed input. (2) Background augmentation alone: independently resample shape and site from the four valid combinations for each digit in each epoch, reconstructing the current view. (3) Use the same augmented input schedule with the paired stable-content target. (4) Use that schedule with full-image reconstruction weighted by a fixed isotropic Gaussian centered at (13.5,13.5), sigma 7 pixels, normalized to mean one. This is a soft spatial prior on the reconstruction error, with no learned attention or inference-time mask. Keep the original fixed marked views and full-pixel reconstruction for the common fine-tuning stage. Compare arms 2-4 to isolate the target or Gaussian weight at identical augmentation; compare arms 1-2 to isolate augmentation. Use no test-based tuning. Record marked ACC in the outermost quartile by clean digit centroid distance from image center as a descriptive check of the centering assumption. These are naturally occurring offsets on MNIST.
